ChineseSimplified.isl is the Chinese (Simplified) translation for Inno Setup,
downloaded from the upstream project's translation directory:

https://raw.githubusercontent.com/jrsoftware/issrc/refs/heads/main/Files/Languages/ChineseSimplified.isl

Translator attribution is preserved in the file header. This file is bundled
with the installer source so a fresh Inno Setup installation can build the same
Chinese-language setup wizard.
